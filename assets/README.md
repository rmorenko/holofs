# assets/

`sample.png` — изображение **kodim23** из набора Kodak True Color (768×512,
public domain). Классический эталон в литературе по обработке изображений.

Источник: <https://r0k.us/graphics/kodak/>

Если файла нет (свежий клон без скачки), демо упадёт в синтетическую мандалу.
Чтобы получить:

```bash
curl -L -o assets/sample.png https://r0k.us/graphics/kodak/kodak/kodim23.png
```
