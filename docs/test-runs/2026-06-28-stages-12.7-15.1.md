## §25 — Orphan-shard GC

Real orphan scenario (PUT unique → PUT-replace with different unique
bytes → wipe version archive → GC):


## Doc drift uncovered (low-pri fix queue)

1. **§19** — example uses `curl -s 'http://.../api/file_metrics?name=...'` (GET).
   The endpoint is POST-only (returns `405 Method Not Allowed`,
   `allow: POST`). Correct command:
   ```sh
   curl -s -X POST -d 'name=photos/landscapes/mountain.png' \
        http://127.0.0.1:8787/api/file_metrics
   ```
2. **§14** — SSE example references `/events`; the actual route is
   `/api/health/events`.
3. **§19 / §21** — claim that brand-pair `logo-1.png` / `logo-1-wm.png`
   share **low-band** shards and diverge in **high-band**. Our
   synthetic `make_brand_watermark` perturbs the image enough that
   the observed pattern is the **opposite**: zero shared shards in
   the coarsest layer, 48 shared in the highest. The `robust_copy_score`
   field reports negative values (-39…-44) for every brand-pair
   neighbour. The **mechanism works correctly**; the **test data
   doesn't exhibit the documented case**. Either weaken the
   watermark in the generator or substitute real watermarked
   photographs.

## Other observations (non-blocking)

4. `/api/fingerprint/photos/abstract/mandala-a.png` returns
   `0000…` (48 bytes of zero). Other images (`mountain.png`,
   `yosemite-sunset.jpg`, `noise-rgb.png`) return non-trivial
   hashes. mandala-a is highly radially symmetric so the per-block
   DCT-bucket hash legitimately collapses; not a regression.

5. After the §24 PUT-replace cycle, the cluster monitor logged
   ~480 `low margin margin=-16` warnings against
   `photos/abstract/mandala-b.png` (eight per warning batch, one
   per `(channel, layer)`). The file remains fully retrievable
   (`originality=96.1%`, `GET` returns 200, `file_metrics` reports
   the full 444 shards). The monitor's margin formula appears to
   double-count shards shared with the recently-archived
   `mandala-a` history. Worth investigating but does **not** affect
   data integrity.
